T42 Teletext Editor

Use the editor below to edit the found pages in the converted T34 (T42) file. For help, refer to the guide below.

NOTE: The editor is not available on mobile. Please use a desktop or laptop computer to use the editor.

Using the T42 Teletext Editor

Welcome to the T42 Teletext Editor! This guide will help teach you how to use this editor to clean up teletext pages.

Getting Started

To get started, you must first convert your T34 NTSC WST file to a T42 PAL WST file. The code use for this editor is based on an existing teletext editor used for the Teletext Archive website; the GitHub repository is here. To convert your T34 to T32, simply use the C# (C-Sharp) script found here. If you want to save your work for later editing, click the "Save Work" file. A JSON file will be exported and saved. To continue where you left off, simply import that JSON file into the editor.

Actions

Open T42/Session JSON File

Open T42

After the conversion, a new T42 file will be produced. When you have this file, use the "Open T42/Session JSON File" button to select it. The editor will populate with all the pages found in the teletext stream.

Open Session JSON

Open the JSON file saved from a previous session. You may notice a "Save Work" button this section. The next point talks about what that does and what a session JSON file is.

Save Work

You can save your progress, which include all edits, at anytime by clicking this button. A JSON file with the extension .session.json will be saved to your computer. When you're ready to work with the file again, use the same "Open" button and select the session JSON file. Note that this is NOT the final file that will be used with the teletext viewer. To export the final JSON, see the next point in this list.

Export

All pages as JSON

When you have finished making all the edits you wanted to make, click this option to genreate the final JSON file that will be used with the teletext viewer. It is recommended that you also export the session JSON file for safe keeping in case you want to go back and make additional edits to any of the pages. You cannot open the final JSON file, saved as .final.json, in the editor.

This page as PNG (960 x 1000)

To save only the current page as a PNG file, click this option.

All pages as PNGs (ZIP)

Use this option to save all pages as PNG files. These will be downloaded as a ZIP file.

Using the Editor

Here's a rundown on how to use the editor:

Additional Actions

Highlight missing rows

The editor will highlight empty rows missing from the final page in red. This is enabled by default, but can be disabled if you so choose. Not adding empty rows does not affect the final result.

Reveal concealed text

Some pages may have hidden text that can only be revealed by pressing a "Reveal" key on a teletext keypad, such as answers to a quiz. Enabling this option will show that concealed text.

Treat each transmission as a subpage

The final page is a combined page made from the various versions of a specific page that were seen in the T42. While the code accounts for pages with subpages and will display them, there may be a couple of pages that the code claims to not have subpages, yet they actually do. This can be verified by looking through each page version at the top of the editing viewers (more on that later).

Use this option to separate each page, including the final versions, into their own subpage. Choose the subpages, then click the "Separate as own subpage" button in the "Pages" section to save those specific pages as editable subpages.

Sort out subpages automatically

This option, enabled be default, automatically sorts subpages based on the page's subcode. Subpages are sorted by number ("Subpage 1," "Subage 2," etc.)

The code also looks for damaged subcodes whose pages contain very similar content, fixes the subcode, and merges that page into the correct subpage (or page). For example, for subpages, say P118 has 2 subpages (P118/0001 and P118/0002). However, damaged headers cause there to be a third subpage (P118/0701) that contains the same content (albeit less readable) from subpage 1 (P118/0001). The code fixes the damaged header and chooses which subpage to merge the data into based on the content on the page. While this works as expected, some headers may be too damaged or content too garbled, so the code will still output pages with incorrect subcodes (); these can be removed.

Transmitted Versions

To visually see the different versions of each page you're editing, use the provided image gallery. Clicking on a page version will show it in the comparison viewer.

NOTE: Click on a page in the "Pages" section first, then click on the various page versions in the "Transmitted Versions" gallery to apply edits to the page you initially clicked on.

Pages

  1. You can filter pages by page numbers (e.g., 110).
  2. All pages and subpages (if applicable) will be displayed in a list. Click on a page to view it.
  3. To view all page versions (and subpages for a certain page number), enable the "Treat each transmission as a subpage". The list will update and allow you to select each individual version. Refer to the article above for more information.

Managing Pages

Use the options in this section to to modify the various pages in the teletext stream.

  1. Remove from list: Remove the selected page from the final list.
  2. Remove checked: Removed only the pages whose checkboxes have been checked.
  3. Separate page as own subpage: Save the current page as a subpage. To save multiple pages, check the checkboxes for each page. This is mainly used when the "Treat each transmission as a subpage" switch is enabled.
  4. Restore last removed: Restores the previously removed page. Click again to go back another step.
  5. Restore all removed: Brings back every removed page at once.

Cursor

  1. This section shows the current position of the cursor and the value of the selected byte.
  2. You can update the byte's value by typing it into the input field, then clicking "Update".

Teletext Page Viewers

Teletext Comparison Viewer

  1. Final page (editable): This is the editable page where characters can be added or deleted.
  2. To add text characters, just type them. You can also use the "Character Map" section at the bottom.
  3. To add mosaics, refer to the "Character Map" article.
  4. Compared version: This is the page you're comparing the final version to.
  5. Content from this comparison page can be copied and pasted into the final page. You can also copy and paste characters from within the final page display.

To edit information in the editor window, put the cursor where you want it, then begin typing or inserting characters. Keyboard commands are supported. A list is below:

Keys Page Window Function
Arrow keys Final page Move the cursor
Arrow keys / Shift + arrows Comparison view Move / Extend the selection
Ctrl/⌘ + C Comparison view Copy the selection
Ctrl/⌘ + A Comparison view Select the whole page
Esc Comparison view Clear the selection

There are also buttons below the viewer that perform the same copy/paste functions.

Editor Color Codes

Both viewers make uses of a few colors to note changes between the final edited page and the page used for comparison. The comparison viewer is the priamry viewer to pay attention to. Here's what each color means:

  1. Red (solid rectangle): The row seen in the final page is missing from this version of the page. Refer to the "Highlight missing rows" article for more information.
  2. Green (outline): A compared version of the page has data in a row that the final page is missing; this is likely data missing needed for the final page.
  3. Yellow (outline): Both page versions have data in this row, but the data in the comparison row differs; compare both rows and consider whether the final page needs updated.

Row Comparison

This shows any different, missing, or new rows that are not present in the final page, but are present in the comparison page. To only insert one row, click the "Use this row" button. To insert all missing rows, click the "Fill all missing rows" button.

Page

Number / Subcode

This shows the current page's number and subcode. This cannot be edited.

Character Map

This shows all current available characters in the font. "Text" characters are shown by default. To insert mosaic characters, click the "Mosaic" option.

Color Codes

To change the text color, click on the icon (shown as a capital "A") above the color square. Place the cursor before where you want to change the text color. To change the color of a mosaic character, click on the color square.

To change a row's background color, put the cursor at the beginning of the row you want to change (column 1), then click on one of the text color icons to insert the color code. This will change the color of the entire row and keep the current color of the text inside the row. To add a new row, put the cursor in column 1, insert a text color code, then click the "New" button to insert a new row with that color. To insert a black row, do the same steps, but click the "Black" button instead.
